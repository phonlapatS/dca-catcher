# DCA Catcher Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the DCA Catcher bot to deliver deep analytical buy plans in concise Thai language, utilizing technical indicators, volume anomaly detection, and macro market sentiment.

**Architecture:** A robust data transformation pipeline generating RSI, 50-day MA, and volume anomalies, fed into an upgraded Gemini prompt engine with model-tiering fallbacks, and governed by a state-machine-based anti-spam alert system.

**Tech Stack:** Python, `ta` library (Technical Analysis), `requests` (Scraping), Gemini API

## Global Constraints

- All explanations, reasons, and advice must be in Thai, straight to the point, and easy for a busy person to scan.
- The backend monitors stocks every 30 minutes to preserve API quota.
- If a model hits a 429 Quota limit, it automatically fails over to the next model in the list.
